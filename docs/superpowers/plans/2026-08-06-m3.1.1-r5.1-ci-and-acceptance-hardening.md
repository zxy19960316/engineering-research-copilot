# M3.1.1 r5.1 CI and Acceptance Hardening Implementation Plan

> **For agentic workers:** Execute this plan task-by-task in the current narrow branch. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repair exact-HEAD cross-platform CI, preserve and diagnose the immutable r5 F02 failure, turn the r5 acceptance audit into a hash-bound cross-validator, and correct current status without closing M3.

**Architecture:** Treat historical JSON identity as two layers: immutable Git blob identity plus canonical JSON SHA-256, while retaining worktree raw SHA-256 only as a diagnostic observation. Keep r5 consumed artifacts read-only, write all new F02 and erratum evidence under a new r5.1 diagnostics root, and make the acceptance auditor independently reload and bind every declared artifact.

**Tech Stack:** Python 3.12/3.13 standard library, `unittest`, Git object database, canonical UTF-8 JSON, GitHub Actions on Ubuntu and Windows.
