> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove, entirely offline and without granting authority, that a future M4.2 authorization/claim/dispatch protocol would be immutable, single-use, fail-closed, batch-terminal, visibility-isolated, and cross-platform consistent.

**Architecture:** Add one closed protocol-proof artifact, one closed schema, and one read-only auditor under the existing M4.2 authorization namespace. The auditor independently reads immutable Git blobs, recomputes the 60 request bindings and matrix projection, evaluates a pure virtual claim state machine, scans for forbidden runtime artifacts, and emits one deterministic JSON summary. CI runs the same proof plus the existing read-only PowerShell request verifier on Windows PowerShell 5.1 and Ubuntu PowerShell 7; no builder, writer, token, claim, task context, result root, judge, unblinding, or aggregation path is added.

**Tech Stack:** Python 3 standard library, `unittest`, JSON Schema Draft 2020-12, Git object reads, Windows PowerShell 5.1, PowerShell 7, GitHub Actions.

## Interfaces

- `request_binding_sha256(task: Mapping[str, object]) -> str`: independently frames the ten frozen M4.2 request-binding fields and returns a lowercase SHA-256.
- `matrix_projection(manifest: Mapping[str, object]) -> dict[str, object]`: returns exact matrix counts, uniqueness counts, order hashes, and the matrix binding hash.
- `simulate_claim(*, state: str, preconditions: Mapping[str, bool], requested_task_count: int, post_claim_failure: bool = False) -> dict[str, object]`: pure virtual state transition; performs no writes and dispatches no task.
- `simulate_batch_failure(batch_sequence: int) -> dict[str, object]`: returns the deterministic stop trace and successor requirement for one of six virtual batches.
- `visibility_projection() -> dict[str, object]`: returns the exact task-visible allowlist and all closed visibility flags.
- `discover_forbidden_paths(repo_root: Path, present_paths: set[str] | None = None) -> list[str]`: returns sorted forbidden M4.2 runtime paths.
- `audit_protocol_proof(repo_root: Path = REPO_ROOT, *, proof_data: Mapping[str, object] | None = None, verify_git: bool = True, present_paths: set[str] | None = None) -> dict[str, object]`: returns deterministic proof status and errors without writing.

```python
def simulate_claim(*, state, preconditions, requested_task_count, post_claim_failure=False):
    if state != "VIRTUAL_UNCONSUMED":
        return transition("REJECTED_ALREADY_CONSUMED", state, state, 0, 0, True)
    if requested_task_count != 60:
        return transition("REJECTED_PARTIAL_AUTHORITY", state, state, 0, 0, False)
    if set(preconditions) != set(PRECONDITION_NAMES) or not all(preconditions.values()):
        return transition("REJECTED_PRE_DISPATCH", state, state, 0, 0, False)
    if post_claim_failure:
        return transition(
            "STOPPED_PROTOCOL_OR_INFRASTRUCTURE_FAILURE",
            state,
            "VIRTUAL_TERMINAL_FAILED",
            1,
            60,
            True,
        )
    return transition("SIMULATED_CLAIM_ACCEPTED", state, "VIRTUAL_CONSUMED", 1, 60, False)
```
