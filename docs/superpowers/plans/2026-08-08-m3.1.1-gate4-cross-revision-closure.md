```python
def parse_strict_object(raw: bytes) -> dict[str, Any]:
    if raw.startswith(b"\xef\xbb\xbf"):
        raise ValueError("utf8_bom_forbidden")
    def pairs(items):
        value = {}
        for key, item in items:
            if key in value:
                raise ValueError("duplicate_key")
            value[key] = item
        return value
    value = json.loads(
        raw.decode("utf-8", errors="strict"),
        object_pairs_hook=pairs,
        parse_constant=lambda token: (_ for _ in ()).throw(ValueError(token)),
    )
    if not isinstance(value, dict):
        raise ValueError("object_required")
    return value
```

Use `git cat-file -e <head>^{commit}`, `git merge-base --is-ancestor <head> HEAD`, `git rev-parse <head>:<path>`, and `git show <head>:<path>`. Reject absolute paths, `..`, paths outside the explicit result/input prefixes, unavailable commits, missing blobs, wrong OIDs, wrong raw/canonical hashes, and non-ancestor evidence heads.
