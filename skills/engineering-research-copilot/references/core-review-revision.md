# 审稿、修改与润色

当研究者已经有较明确的选题、开题方案、研究计划、提纲或论文，并要求批评、模拟同行评审、编辑综合、修改计划、获准编辑、复审或最终润色时，应用本协议。审稿默认只读；提案者或作者的信心不能替代独立质疑。

## 确定审查边界

确认制品及版本、文档类型、审查要支持的决策、用户提供的目标期刊或读者、审稿人可见证据、要求的深度、已知约束，以及用户只需要诊断还是随后还要修改。缺少数据、代码、补充材料、图表、全文或充分明确的研究目标时，说明哪些方面无法评估。

## 生成独立审稿报告

选择三到五个适用于当前材料且不重复的视角。一般工科论文可从以下视角选择：

- **贡献与定位**——创新性、重要性、文献覆盖、主张强度和引文完整性；
- **方法与有效性**——设计、对照、统计或 VVUQ、泄漏、不确定性、可复现性，以及结果能否支持主张；
- **工程相关性与风险**——运行边界、可行性、失效模式、迁移、安全、部署和实际价值；
- **替代解释**——竞争机制、混杂因素、反例、负面结果和反方质疑；
- **编辑或期刊匹配**——已知目标期刊时，审查读者、结构、完整性、清晰度和可能的直接拒稿风险。

某个视角与其他视角重复时，调整或省略。综合前保持各报告逻辑独立；不要把一位审稿人的报告作为另一位审稿人的证据，也不要让审稿人直接编辑其正在评价的文稿。

每条意见包括：

- 严重程度：致命、重大、次要或可选；
- 文稿或证据锚点；
- 问题及其违反的科学或表达原则；
- 对有效性、解释、可复现性、贡献或录用的影响；
- 所需证据、分析或修复；
- 修复后仍存在的风险。

要求每位审稿人指出最强的可辩护贡献、最重要的弱点和最小判别性下一项检查。区分“缺少证据”和“缺少解释”。

## 进行编辑综合

由独立的编辑角色接收各份报告。合并真正重复的问题，但保留来源。保留分歧，并解释分歧来自不同假设、证据访问、优先级还是标准。不要制造共识。

返回：

- 最强的可辩护贡献及当前证据边界；
- 致命缺陷和可能的直接拒稿风险；
- 必须、建议和可选修改；
- 相互冲突的审稿判断以及解决所需条件；
- 修改前还需要的证据或作者决定；
- 按顺序排列的修改计划。

编辑负责排序，不静默推翻审稿意见，也不自行授权修改文稿。

## 维护问题台账

每个可行动问题建立一行：

| 字段 | 必填内容 |
|---|---|
| **问题 ID** | 本轮审查中的稳定标识。 |
| 来源 | 审稿人和原始锚点。 |
| 严重程度 | 致命、重大、次要或可选。 |
| 问题与影响 | 问题是什么以及为什么重要。 |
| 所需修复 | 证据、分析、决定或文本变更。 |
| **作者决定** | 接受、说明理由后拒绝、修改、延期或未决定。 |
| 计划变更 | 准确行动和受影响位置。 |
| **已实施变更** | 获准后的补丁或制品/版本身份。 |
| 核验 | 复审结果及其锚点。 |
| 剩余风险 | 尚未解决的科学或编辑风险。 |

保留被拒绝或延期的问题。没有复审核验时，流畅的改写不能关闭问题。

同一请求包含修改或复审时，始终以紧凑形式展示问题台账，不要用不可追踪的叙述摘要替代。仅诊断的审稿可以把台账作为可行动综合结果，但不实施修改。

## 在作者控制下修改

诊断不会自动授权编辑。涉及主张、解释、方法、结果、局限或贡献定位的争议问题及变更，都请作者决定。只实施已获准的修改；对实质变更保留原义与修改后含义，并解释理由。

所需修复依赖新数据、新分析、新实验、来源核验、专家判断或扩大主张决策时，把它标为证据工作，不要虚构文字修复。

## 复审实际修改

针对每项已接受问题进行**定向复审**：检查实际改动段落或制品，确认所需修复是否满足，发现补丁引入的新问题，并更新核验结果和剩余风险。

随后进行**全局一致性检查**，覆盖摘要、引言、方法、结果、讨论、结论、术语、假设、样本量、数值与单位、图表、引文、局限和贡献主张。局部修复不能在其他位置制造矛盾。

默认最多进行**两轮审稿—修改循环**，除非用户另行指定有界预算。诚实地以**等待用户决定**、**因缺少证据而阻断**或**用户停止**结束；不得代表期刊或审稿人宣布录用。

## 以不改变含义的润色收尾

只有科学问题已经解决或明确延期后，才进行**保义润色**。改善清晰度、流畅性、简洁性、段落逻辑、术语、衔接和读者适配，同时保留数值、单位、因果强度、不确定性、局限、引文范围和作者声音。

不得加强主张、改变数值含义、消除不确定性、添加证据，或用措辞让未解决问题消失。润色后，将每项实质主张与润色前版本对照，并报告任何可能改变科学含义的措辞。
